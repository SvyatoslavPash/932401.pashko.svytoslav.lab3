# Предприниматель и стартапер — идеи и метрики

Учебный адаптивный лендинг по теме **«Предприниматель и стартапер»**.  
Вариант 16. Автор: **Пашко Святослав**.

## Описание проекта

Одностраничный сайт рассказывает о предпринимателе, содержит подборку стартап-идей, дашборд ключевых метрик и форму обратной связи.

Основная цель работы — закрепить навыки адаптивной вёрстки с использованием **Flexbox**, **CSS Grid**, медиа-запросов и семантических тегов HTML5.

## Возможности

- Горизонтальное адаптивное навигационное меню на Flexbox.
- Flex-карточки стартап-идей: 4 / 2 / 1 в ряд в зависимости от ширины экрана.
- Grid-дашборд метрик: **MAU**, **LTV**, **CAC**.
- Визуализация метрик через `<meter>`.
- Заглушки графиков внутри карточек метрик.
- Адаптивность для планшетов и мобильных устройств.
- Отсутствие горизонтальной прокрутки.
- Семантические теги: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Форма обратной связи с обязательными полями и стилями фокуса.

## Технологии

- **HTML5**
- **CSS3**
  - Flexbox
  - CSS Grid
  - Media queries
  - CSS-переменные
